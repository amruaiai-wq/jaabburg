# Burger Exploded Ingredient Set

12 images generated from the matching assembled burger references using the built-in image generation tool in reference-image edit/variation mode.

Ingredients are interpreted from the reference images, not a verified recipe specification. Original generated PNG files are copied without resizing or post-processing. The contact sheet is a preview layout only.

## Shared Direction

One centered exploded ingredient stack, black/charcoal studio background, realistic premium food photography, clearly visible ingredient layers, sharp textures, warm studio highlights, no labels, text, logos, watermarks or props.

```text
Use case: product-mockup
Asset type: high-resolution burger ingredient breakdown asset

Show the same burger separated into clearly visible floating layers, from top to bottom: glossy sesame top bun, green lettuce, red tomato slices, creamy sauce coating, first yellow cheese slice, first grilled chicken fillet, second yellow cheese slice, second grilled chicken fillet, and bottom bun. Exactly two grilled chicken fillets and two cheese slices.
Input images: Image 1 is the reference for burger identity, ingredient types, color, style, and studio look.
Scene/backdrop: clean dark charcoal/black studio backdrop matching the reference style.
Subject: one centered exploded burger only, all components aligned vertically with visible air gaps between ingredient layers. Sauce is a natural coating on food, not a solid floating disc.
Style/medium: realistic premium food product photography, sharp appetizing textures, commercial menu asset.
Composition/framing: front-facing centered vertical stack, all ingredients and both buns fully visible with comfortable margins, no assembled burger beside it.
Lighting/mood: soft studio highlights, natural shading, rich contrast.
Constraints: preserve the reference ingredients and premium look; chicken clearly grilled, not breaded or beef. Do not add labels, text, logos, watermarks, plates, hands, props or extra ingredients. Show the breakdown without written words.
```
